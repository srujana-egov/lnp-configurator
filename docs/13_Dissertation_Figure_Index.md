Use the same dataset.

=============================================================================

Describe the figure.

Explain its relevance.

Avoid implementation details.

Good

The figures in this dissertation are not decorative illustrations.

They are evidence supporting the architectural design, implementation and evaluation of the proposed AI-Assisted DIGIT Application Configurator.

Every figure should contribute directly to explaining the architecture, validating design decisions or communicating evaluation results.
